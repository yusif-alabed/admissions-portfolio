# Exploratory ESRD Clinical-Data Analysis

## Overview

This project investigates patterns in routine clinical and metabolomic variables in end-stage renal disease (ESRD) and healthy controls. It uses principal component analysis (PCA) and Random Forest classification to explore the structure of the data.

## Reproducibility and scope

The data analysed originated from the public, de-identified human cohort reported by Wang et al. (2020) and deposited in MetaboLights (accession `MTBLS700`). The source data are not redistributed here; readers should obtain them from the original repository and follow its terms of use.

This is an exploratory, cross-sectional project. It does not provide a validated diagnostic model, clinical prediction, or medical advice. Any reported classifier performance should be interpreted in the context of the paper's methodology and limitations.
