## Portfolio principles

This is a public portfolio. It includes work that can be independently inspected: written work, analysis notebooks, figures, source material, and project documentation. It deliberately excludes recommendation letters, application essays, identity documents, school records, and other private material.

## Academic integrity and research note

The ESRD project is an exploratory secondary analysis of a public, de-identified dataset. It is not clinical advice or a validated diagnostic tool. The code and figures are supplied so readers can examine the workflow, methods, and limitations.
