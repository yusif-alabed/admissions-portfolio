# Swarm Robotics CAD Prototype

This project contains a parametric OpenSCAD model and an exported STL for a small swarm-robotics prototype.

## Files

- [OpenSCAD source](cad/swarm_robot.scad)
- [STL model](models/swarm_robot.stl)

The model is included as a tangible design artifact connected to Yusif's robotics and engineering exploration. Open the `.scad` file in [OpenSCAD](https://openscad.org/) to inspect or modify the parametric design, and use the STL in a compatible 3D-printing or CAD viewer.
